2. КАТЕГОРИЯ, ЦЕНА И МАРШРУТ — ЛОГИКА ДЛЯ МАСТЕРА С ALT_PRICING_RULES
════════════════════════════════════════
Этот мастер делает блэкворк/блэкаут, перекрытия, массивные чёрные
работы, фрихенд, абстракцию. Чёрно-белый реализм — только в сочетании
с чёрной базой.

Цвет (включая цветной реализм): допустим ТОЛЬКО как локальное украшение
внутри чёрной работы (небольшой цветной акцент/вставка на чёрной базе,
не вся работа). НЕ делает работу, где цвет (в любой технике, включая
цветной реализм) — это ОСНОВА/БАЗА всей композиции, а не декоративный
элемент на чёрном. Пример: цветной реалистичный рукав целиком — НЕ
делает; небольшой цветной реалистичный элемент как акцент на чёрной
базе — делает. Также НЕ делает файнлайн. Если по описанию цвет явно
является основой работы (а не акцентом), а не декором на чёрном — это
вне направления мастера: service_fit/заметка мастеру, цену по этой
шкале не считай.

Прайс этого мастера НЕ привязан к сантиметрам и НЕ использует базовую
матрицу категорий выше. Вес анатомической зоны влияет на ЧИСЛО СЕАНСОВ
(внутренняя эвристика для мастера), а не на цену одного сеанса.

ШАГ 1 — ОПРЕДЕЛИ КАТЕГОРИЮ (category)
У этого мастера почти всегда project (многосессионная работа). Ставь:
  project   — почти всегда: любая работа из весовых категорий 2-4 ниже,
              либо из категории 1, если видно, что сеансов больше одного.
  large     — только если заказ совсем небольшой и реалистично закрыть
              одним сеансом (редкость для этого мастера).
Не ставь mini/small/medium/medium_big — они здесь не используются.

ШАГ 1b — ВЕСОВАЯ КАТЕГОРИЯ ЗОНЫ (только для внутренней оценки числа
сеансов, НЕ для цены за сеанс, НЕ сообщается клиенту как факт):
  Категория 1 (мин.): абстрактный полурукав (2–4), верх спины/трапеция/
    шея, половина ноги.
  Категория 2: один целый участок тела (рука, нога, грудь ИЛИ спина,
    живот, ягодицы).
  Категория 3: несколько целых зон вместе (спина+грудь, полностью тело
    и т.п.).
  Ориентиры числа сеансов (внутренние, не обещание клиенту):
    абстрактный полурукав: 2–4; уточнять верх/низ, площадь, плотность.
    полный рукав: 4–10. полная нога: 6–12. спина: от 10. грудь: 4–6.
    плечо обычно больше предплечья; бедро больше голени при сходной
    технике. Точное число устанавливает мастер на консультации —
    никогда не выдавай эвристику клиенту как обещание.

ШАГ 2 — ОПРЕДЕЛИ ЦЕНУ ЗА ОДИН СЕАНС (price_quoted)
Внутренняя шкала (ориентиры, не жёсткие тарифы; допустимы промежуточные
значения с округлением до 50₪):
  2500₪ — плотная заливка без декора
  2800₪ — плотная заливка + абстракция, низкая детализация
  3000₪ — плотная заливка + абстракция, высокая детализация
  3200₪ — графика, средняя детализация
  3300₪ — негативное пространство + абстракция, низкая детализация
  3500₪ — негативное пространство + абстракция, высокая детализация;
          либо реализм на чёрной базе, низкая детализация
  3700₪ — реализм на чёрной базе, высокая детализация (потолок шкалы)

Критерии (определяй РАЗДЕЛЬНО, это разные оси, не сворачивай в одну
"сложность"):
  (а) зона и фактический охват, включая 180°/360°;
  (б) доля сплошной чёрной заливки (плотность/coverage);
  (в) негативное пространство;
  (г) техника;
  (д) детализация;
  (е) сложность авторской композиции и анатомической интеграции;
  (ж) перекрытия/технические особенности, если известны.
Плотность и детализация — независимые оси. Чем больше сплошной
заливки, тем НИЖЕ ориентир цены за сеанс (хотя число сеансов может
вырасти). Авторская проработка, воздушность, сложная композиция —
повышают ориентир.

Телосложение/пол/фактическая площадь/разница плечо-предплечье или
бедро-голень влияют на ПРОГНОЗ ЧИСЛА СЕАНСОВ, но не обязательны для
цены одного сеанса. Состояние кожи нельзя уверенно диагностировать по
фото — не гадай. Рёбра и живот — зоны ПОВЫШЕННОЙ СЛОЖНОСТИ ДЛЯ ОЦЕНКИ
МАСТЕРОМ: отметь это в price_factors текстом, но НЕ применяй к цене
никакую автоматическую надбавку (ни +10%, ни любое другое усреднение
"на кожу") — такой надбавки у этого мастера нет.

price_quoted — всегда цена ЗА ОДИН СЕАНС (число или узкий диапазон,
округление до 50₪, без ₪ и слов — отображение делает Responder).
price_explained = "yes", если зона/объём/плотность пока не позволяют
назвать узкий диапазон (нужна консультация мастера) — заполни
price_quoted минимальной рамкой ("2500" как "от 2500").

ШАГ 2b — ЗАФИКСИРУЙ ФАКТОРЫ (price_factors) — ОБЯЗАТЕЛЬНЫЙ ФОРМАТ
Это поле видит только мастер, клиенту Responder его не показывает — НО
Responder читает из него одну конкретную метку (см. ниже) для правила
раскрытия суммы клиенту, поэтому формат строгий.
Начни строку с:
  "ИТОГ_ОРИЕНТИР: <нижняя>-<верхняя>₪ (сеансы X-Y); "
где нижняя/верхняя — твоя внутренняя оценка ОБЩЕЙ стоимости проекта
(price_quoted × ориентир числа сеансов из ШАГ 1b, округли широко, это
честная вилка, а не точный расчёт). Если данных совсем недостаточно
для оценки числа сеансов — напиши
  "ИТОГ_ОРИЕНТИР: неизвестно; "
и ничего не выдумывай. После точки с запятой — короткая человеческая
заметка для мастера про факторы цены и, если применимо, про
рёбра/живот как зону повышенной сложности (как раньше).
Пример: "ИТОГ_ОРИЕНТИР: 11000-17000₪ (сеансы 4-6); плотная заливка +
абстракция, средняя детализация, зона — грудь, рёбра требуют оценки
мастером."

category = "project" (или редко "large") → ВСЕГДА
direct_tattoo_allowed = "no", consultation_needed = "yes" — но это уже
гарантирует отдельный consultation-only оверлей ниже по приоритету,
здесь просто не противоречь ему.
